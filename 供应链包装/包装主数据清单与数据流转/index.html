    包装主数据清单与数据流转¶

    适用场景：制造业四类包装（来料 / 翻包 / 厂内周转 / 出货）的统一数据管理 核心原则：一个包装层级一个编码 + 一个版本；理论值用于计划与拼载，实测值用于执行与结算，两者并存、互不覆盖、偏差可追溯。

    一、数据流转概览¶

    供应商来料包装 → 收货入库 → 翻包·形态转换 → 厂内周转包装 → 成品出货包装 → 装车·拼载
   (PKG-SUP)      (HU单元)    (PKG-INT新编码)   (PKG-RTN资产)    (PKG-FIN/CUS)   (装载单元链)

↑ 理论包装数据（Pack Spec）：量产前冻结发布 → 装车拼载 / 运费报价 / 包材MRP
↓ 实际包装数据（实测采集）：DWS体积重量 / 装箱称重 / 收货扫码 → 装车复核 · 运费对账 · 偏差分析
⟲ 偏差闭环：偏差 > 阈值 → 复核工单 → ECN 修正理论值 / 修正实测基线

    系统落位：PLM 包装规格定义 | ERP 主数据/HU | WMS 翻包/库位 | MES 箱码/托码层级 | TMS 拼载/结算

    链条上每一次「包装单元变化」都必须生成新的包装编码，否则拼载、结算、盘点会在断点处失真。

    三、字段字典¶

    1. 标识与版本¶

    字段 标识 类型 维护方 校验规则 / 说明
    包装编码 PKG_ID 字符 包装工程 全局唯一；前缀 PKG-SUP / INT / RTN / FIN / CUS
    包装版本 PKG_VER 整数 包装工程 参数变更即升版，旧版本保留可追溯
    生效日期 VALID_FROM 日期 包装工程 拼载按「出货日」取生效版本，不得使用未来版本
    物料/成品编码 MAT_NO 字符 ERP 必须存在且状态有效；一物料同场景只能一个生效版本
    包装层级 LEVEL 枚举 PLM 单件/内包装/箱/托/柜，父子关系必须闭环
    包装类型 PKG_TYPE 枚举 包装工程 SUP/INT/RTN/FIN/CUS，决定必填项集合

    2. 物理参数（理论值）¶

    字段 标识 类型 维护方 校验规则 / 说明
    外箱尺寸 L_W_H 数值 mm PLM 公差 ±5mm；超限需校验车/柜内尺寸
    净重 NET_WT 数值 kg PLM = BOM 单件重 × 每箱数，偏差 >3% 告警
    皮重 TARE_WT 数值 kg 包装工程 周转箱/托盘皮重固定，禁止手工改动
    毛重 GROSS_WT 数值 kg 系统计算 = 净重 + 皮重，不允许手工录入
    每箱数量 PACK_QTY 整数 包装工程 ≤ MOQ 且为采购下单倍数；写入采购订单
    每托箱数 CASES_PER_PLT 整数 包装工程 = 堆码层数 × 每层箱数
    堆码层数 STACK_LAYERS 整数 包装工程 不得超过堆码测试允许值
    是否可叠 STACKABLE 布尔 包装工程 不可叠时层数强制为 1
    托盘规格 PLT_SPEC 枚举 PLM 标准托 1210/1208 或客户专用托，需带托高
    目标装载率 LOAD_RATE 百分比 物流 低于目标触发拼载方案复核

    3. 实测参数（实际值）¶

    字段 标识 类型 维护方 校验规则 / 说明
    实测毛重 ACT_GROSS 数值 kg 称重/DWS 与理论偏差 >3% 生成复核工单
    实测尺寸 ACT_DIM 数值 mm DWS 偏差 >5mm 告警，影响拼载重新计算
    采集时间 MEAS_TIME 时间戳 采集系统 保留审计轨迹，不得覆盖历史值
    采集来源 MEAS_SRC 枚举 采集系统 称重设备/装箱工位/DWS/抽检
    偏差结论 DEV_FLAG 枚举 质量/工程 正常 / 复核中 / 已修正理论 / 已让步

    4. 业务与资产管理¶

    字段 标识 类型 维护方 校验规则 / 说明
    是否循环包装 RETURNABLE 布尔 包装工程 为真时必须关联资产台账编码
    资产编码 ASSET_ID 字符 物流/资产 一箱一码（RFID/二维码），登记在册/在制/在途/维修/报废
    循环天数 CYCLE_DAYS 整数 物流 需求量 = 日均用量 × 循环天数 ×(1+安全系数) + 维修报废
    客户标签类型 LABEL_TYPE 枚举 客户要求 SSCC/GTIN/客户看板格式，不一致禁止出货
    包装测试报告 TEST_RPT 附件 包装工程 跌落/堆码/振动（ISTA 系列），出货包装必附
    翻包作业标准 REPACK_WI 附件 工艺 翻包件必填，含作业步骤、防护要求、工时
    翻包损耗率 REPACK_LOSS 百分比 工艺 用于翻包成本分摊与供应商包装改善
    翻包后皮重变化 TARE_DELTA 数值 kg 工艺 翻包必重称，用于线边料架载重与 AGV 限重校验
    包材回收责任方 RECYCLE_OWNER 枚举 采购 供应商 / 我方 / 第三方循环池，写入采购协议

    四、系统级硬性校验规则（建议做成阻断）¶

    1. 毛重 ≠ 净重 + 皮重 → 阻断保存
    2. 每托箱数 ≠ 堆码层数 × 每层箱数 → 阻断保存
    3. 堆码层数 > 包装测试允许层数，或「不可叠」但层数 >1 → 阻断
    4. 同一物料同一场景存在两个「生效中」版本 → 阻断发布
    5. 循环包装未关联资产编码，或皮重为空 → 阻断
    6. 出货包装标签格式与客户规范库不一致 → 阻断出货放行
    7. 理论与实测偏差超阈值（毛重 ±3%、尺寸 ±5mm）→ 生成复核工单，未关闭前拼载结果标注「待确认」
    8. 理论数据未发布即进入发运计划 → 阻断拼载计算，不得用默认值兜底

    五、落地顺序建议¶

    先统一「包装编码 + 版本 + 层级」三项，把四类包装挂进同一张主数据表；再补理论/实测双字段与偏差工单；最后接拼载系统与运费结算。反过来做（先上优化算法）一定会因为数据不可信而退回人工。
