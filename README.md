# 个人知识库

基于 **MkDocs Material**（GitHub 星标最高的静态知识库方案，27.6k+ stars）搭建的个人知识库。

## 内容目录

- [供应链包装](docs/供应链包装/index.md) — 包装主数据、业务流与数据流设计
- [自媒体运营](docs/自媒体运营/index.md) — B站账号分析与内容改造

## 本地预览

```bash
pip install -r requirements.txt
mkdocs serve
```

浏览器打开 http://127.0.0.1:8000

## 在线访问

推送到 main 分支后，GitHub Actions 自动构建并发布到 GitHub Pages。
