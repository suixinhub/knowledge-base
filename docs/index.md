# 首页

欢迎来到我的个人知识库。

## 使用方式

- 用左侧/顶部导航浏览各分类
- 右上角支持全文搜索（中文已启用）
- 每页标题旁有锚点链接，方便引用

## 分类

| 分类 | 内容 |
|---|---|
| [供应链包装](供应链包装/index.md) | 包装主数据、四类包装管理、业务流与数据流设计 |
| [自媒体运营](自媒体运营/index.md) | B站账号数据分析与内容改造 |
| [资料](资料/index.md) | 书籍与长文档归档（高性价比人生指南 PDF 等） |
| [关于本库](关于/index.md) | 原理与架构、方案对比与选型、操作手册 |

## 维护约定

- 新增文档：在 `docs/<分类>/` 下新建 `.md` 文件，并在 `mkdocs.yml` 的 `nav` 中登记
- 图片等附件放 `docs/assets/`
- 每次推送 main 分支自动发布
