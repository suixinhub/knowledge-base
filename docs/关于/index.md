## 一句话概括

**你的笔记就是仓库里的 Markdown 文件，GitHub Actions 每次推送自动把它们编译成静态网页，托管在 GitHub Pages 上。**

所以你同时得到了两样东西：

- 一个**纯文本、带完整版本历史的文件仓库**（数据完全属于你，任何编辑器都能打开）
- 一个**带全文搜索、可手机访问、有固定网址的网站**（读起来像产品文档，不像一堆散文件）

## 三条硬规矩

1. **`docs/` 目录是唯一数据源**。只改这个目录里的文件，不要手动改构建产物。
2. **新增文件必须在 `mkdocs.yml` 的 `nav` 里登记**，否则页面能生成但导航里看不到（只能靠搜索或直达链接访问）。
3. **仓库是公开的**。公司内部数据、客户名称、价格、内部系统截图不要往里放。
