## 核心原则

1. 一个包装层级一个编码 + 一个版本
2. 理论值用于计划与拼载，实测值用于执行与结算，两者并存互不覆盖
3. 换算率（EA→箱→托）只在包装主数据维护，全系统共享
4. 对外单据与结算读快照，不读实时主数据
