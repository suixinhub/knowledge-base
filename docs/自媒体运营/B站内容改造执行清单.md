## 二、改造模板（原位编辑，不删稿不重发）
标题公式（三选一，按产品类型套）：
1. 疑问句式：「XX 到底值不值得买？上手实测」
2. 场景痛点式：「跑步游泳不用带手机？XX 骨传导耳机实测」
3. 对比/避坑式：「XX 是不是智商税？用了一周告诉你答案」

配套动作：
- 标签：补 3~5 个精准 tag（品牌词 + 品类词 + 场景词）
- 简介：第一行放一句结论 + 引导互动（"你觉得值不值？评论区聊"）
- 有"活动"标签的稿件一律保留活动属性，优先改
